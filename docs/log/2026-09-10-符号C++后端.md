# 2026-09-10 符号 C++ 后端实现记录

## 完成内容

- 新增 `Pikachu::SymbolicCppBackend`，支持从 `Expres` 或已 lowering 的 `VISA1` 生成自包含 C++11 源码。
- 支持 MiniOperations 与 MiniRegisters 两种 lowering。
- 支持输入组、参数、多输出、整数/实数/NaN/Inf 常量、四则运算、`sin/cos/exp/log/sqrt`、一元负号和 `pow`。
- 生成函数使用 `extern "C"` ABI，运行时不依赖 Pikachu2，也不分配堆内存。
- 在生成前验证函数名、C++11 关键字、指令操作码、常量索引和寄存器编号，并返回明确状态码。
- `FuncConst::Rvalue()` 现在对内部 NaN 返回真正的 IEEE quiet NaN，不再返回 0。
- `VISA1::RegAllocate` 明确丢弃空闲表中的寄存器 0，强化“Reg0 保留”的不变量。

## 后端测试暴露并修复的 lowering bug

MiniReg 原先跳过所有叶节点，假定叶节点总会在父节点使用点加载。当输入、参数或常量本身也是表达式输出时，这个假设不成立：lowering 会生成 `store output, reg[0]`，随后还可能把 0 放入空闲寄存器表，使后续计算反复覆盖保留寄存器并得到完全错误的结果。

现在输出叶节点会先生成 load，再生成 store，并在存储后安全回收实际寄存器。Test064 特意加入 NaN 和 Inf 常量输出以覆盖这个情况。

## 验证

完成干净构建、Test063 符号微分回归以及 Test064 后端生成测试。随后用独立 G++ 命令编译 MiniOp、MiniReg 两份生成源码和小型调用器；该命令没有链接 Pikachu2：

```bash
g++ -std=c++11 -O2 \
  output/symbolic_generated.cpp \
  output/symbolic_generated_miniop.cpp \
  test/symbolic_backend_driver.cpp \
  -o output/symbolic_backend_test
./output/symbolic_backend_test
```

结果为退出码 0：

```text
generated C++ backend matches the analytic reference.
```

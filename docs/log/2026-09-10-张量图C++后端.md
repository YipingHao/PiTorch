# 2026-09-10：张量图 C++ 后端

本轮新增 `TensorCppBackend`，并把原有 DSL 的 `print.CPU(...)` 接到新后端。

完成内容：

- 输出独立 C++11 源码和稳定的扁平 C ABI；
- 支持输入、参数、常量、`MonoLinear`、`DiLinear`、`MonoNonlinear`、`DiNonlinear`；
- 线性层支持广播、逐元素运算、外积和 dummy-index 归约；
- 线性层输出紧凑的嵌套循环，避免静态逐元素展开拖垮宿主编译器；
- 非线性层复用 `SymbolicCppBackend`，支持融合与拆分的 `MonoFunc` / `DiFunc` cluster；
- 对 DSL 中由 `.` 省略的 singleton 函数维进行恢复；
- 从输出沿真实入边建立依赖顺序，并顺便做不可达节点消除；
- 修正旧 `BackEnd::build` 在正常返回时不关闭输出文件的问题；
- 构建系统加入新的后端翻译单元。
- 修正 `buildTENSORmultiF` 把自身规则误写成 `TENSORVALUE_singleF_` 的入口检查；
- 修正单/双输入非线性 DSL 以“参数元素数必须等于 1”判断调用形式的问题，现在无参数函数走单输入调用，有任意长度参数向量的函数走双输入调用。

验证覆盖：

- 全项目 C++11 干净构建；
- 使用现有 `data/diff.txt` 构造含前向/反向高阶微分的张量图；
- `print.CPU` 成功输出二阶微分网络；
- 对生成的独立源码再次使用系统 C++11 编译器编译。
- 以零参数检查全零结果，以确定性小参数检查全部输出有限；
- 将生成网络给出的 6 个一阶导数与能量的中心有限差分比较，全部通过。
- 另用手工构造的 `DiNonlinear` 图验证参数向量收集，并与 Gaussian-polynomial 公式直接比较通过。
- 同一参数化核也通过 DSL 解析、张量构图、C++ 输出、独立编译和公式比较的完整链路。

验证过程中确认了两个旧图容器的重要行为：重复操作数的出邻接可能被合并，高阶微分种子节点可能位于当前 `graph.content` 之外。新后端按入边依赖遍历，因而不依赖这两个脆弱假设。

当前实现是语义参考版本。验证中曾用静态逐元素展开生成约十万行代码，并观察到宿主编译器内存明显膨胀；因此交付版本已经把线性张量部分改为嵌套循环。后续应正式引入循环 IR，继续处理非线性外层循环、融合与内存规划优化。
